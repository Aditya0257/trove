# web/ — Angular client (placeholder)

**Not built yet.** This folder is a deliberate placeholder.

work) is backend-only: upload → store + sidecar → stub extraction → list by
category → confirm. The API is exercised via `curl`/HTTP for now (see the root
`README.md`).

When we build it, this folder will hold the Angular app that lets a user capture
or upload documents, review-and-confirm extracted fields, and browse by category
and space.
